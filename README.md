# IntoTheUnknown
This 2D Metroidvania game is our graduation project as senior engineering students. Through this project, we aim to learn about game development by designing and building. Along the way, we will tackle technical and creative challenges and collaborate effectively as a team. With this  journey we will grow our passion for game development.

The pre-compiled, fully playable version of "Into the Unknown" has been provided. This version does not require Unity game engine to be installed on the host machine.
The installation steps for the project are given as follows:
1.	Navigate to the GitHub repository link provided above.
2.	Locate the “Releases" section on the right side of the repository page and download the compressed build file.
3.	Extract the downloaded .zip file into a new, empty folder on your desktop or designated directory.
4.	Ensure that the executable file (Into the Unknown.exe) and the associated data folder (Into the Unknown_Data) remain together in the exact same folder. 
5.	Double-click Into the Unknown.exe to launch the game.

For code review, the complete Unity project directory must be downloaded and opened using the Unity Hub.
Prerequisites:
•	Unity Hub: Must be installed on the computer.
•	Unity Editor: Version 2022.3 LTS (Long Term Support) is required to prevent asset serialization errors or script incompatibilities.
Installation Steps:
1.	Navigate to the project’s GitHub repository.
2.	Click the green "Code" button and select "Download ZIP" (or clone the repository using Git via git clone [https://github.com/Tekunokami/IntoTheUnknown]).
3.	Extract the downloaded ZIP file to a local directory on your computer.
4.	Open the Unity Hub application.
5.	In the Projects tab, click the "Add" dropdown and select "Add project from disk".
6.	Navigate to and select the extracted folder (root folder).
7.	Once added to the list, click the project in Unity Hub to launch the Editor.
8.	Upon launching, navigate to the Assets/Scenes folder in the Project window, double-click the Main Menu or starting room scene, and press the Play button at the top of the editor to test the system in the development environment.
